## 💡 About

Merchants usually install one plugin per payment provider: separate settings, separate logs, separate support. **Merchant Services BNP Paribas** brings the three BNP Paribas payment APIs together in **a single plugin per CMS**:

| Solution | What your customers get |
|---|---|
| **Axepta** | Card payments (CB, Visa, Mastercard, Amex), Apple Pay, Google Pay, PayPal — with 3-D Secure |
| **Floa** | Buy now, pay later: Pay Later, 3x, 4x, 10x (France) |
| **BNP Paribas Personal Finance** | Financing solutions |

### Why one plugin

- **One install, one settings screen** — switch each solution on independently.
- **Native back-office flows** — refunds and cancellations from the CMS's own screens.
- **Deferred capture** and **subscriptions** with stored card credentials.
- **Installment simulation** on product and cart pages.
- **Server-verified order statuses** — an order only changes status on a verified payment notification.
- **Logs and a built-in support form** — everything support needs, in one place.

## 🇫🇷 En français

**Un plugin par CMS. Toute l'offre BNP Paribas Merchant Services à l'intérieur.**

Au lieu d'installer un plugin par prestataire de paiement, Merchant Services BNP Paribas réunit les trois API de paiement BNP Paribas dans **un plugin unique par CMS** (PrestaShop, WooCommerce, Magento 2) :

- **Axepta** : CB, Visa, Mastercard, Amex, Apple Pay, Google Pay, PayPal, avec 3-D Secure ;
- **Floa** : paiement fractionné et différé, avec Pay Later, 3x, 4x et 10x (France) ;
- **BNP Paribas Personal Finance** : solutions de financement.

Le plugin offre :

- une seule installation et un seul écran de configuration ;
- les remboursements et annulations depuis les écrans natifs du CMS ;
- la capture différée ;
- les abonnements par carte enregistrée ;
- la simulation d'échéancier ;
- des statuts de commande validés côté serveur ;
- des journaux et un formulaire d'assistance intégré.

Les plugins arrivent bientôt. Suivez les dépôts ci-dessus pour être prévenu de la première version.
